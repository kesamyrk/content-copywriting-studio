# Karina Meisarosh — Content Studio

Отдельный демонстрационный сайт-портфолио текстовых работ.

## Запуск
1. Установите Node.js LTS.
2. Откройте эту папку в VS Code.
3. В терминале выполните `npm install`.
4. Затем `npm run dev` и откройте адрес Vite.

## Сборка
`npm run build`

## Что реализовано
- Адаптивный сайт на React + TypeScript + Vite.
- 12 демонстрационных кейсов в шести категориях.
- Фильтры и поиск по работам.
- Модальные страницы кейсов с задачей, текстом и результатом.
- Отдельный блок «До / после».
- Подход к работе, услуги и контакты.
- Копирование email, переход в Telegram.
- Анимации и поддержка prefers-reduced-motion.

Все кейсы — концептуальные демонстрационные примеры, не коммерческие проекты реальных клиентов. Перед публикацией можно заменить их на собственные работы и обновить контакты.
Для публикации на Vercel: Framework Vite, Build Command `npm run build`, Output Directory `dist`.


## Контакты
Перед публикацией замените `your-email@example.com` и `https://t.me/your_username` в `src/App.tsx` на свои рабочие контакты.
